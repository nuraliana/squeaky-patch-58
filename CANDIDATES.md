# Candidates — Real-Life Patch Notes: The Comedy Changelog

All lines written from scratch for this bounty. No sponsor example, no
other bounty entry, no web source used. Banned/cluttered topics avoided:
hiccup, sneeze, sleep, coffee, "fixed a bug where users…", vacuum,
CAPTCHA, attention heads, out-of-office, and the sponsor's left-ear example.

Scoring per judge brief, 1–5 each (total /25):
(1) one-line patch note for a real-life / human-biology bug, reads as comedy;
(2) genuinely funny on first read, built on a real comedy idea;
(3) reads like a real release note — version number, terse engineering register, fix stated as shipped;
(4) names a specific, instantly recognisable body / everyday bug (wince + laugh);
(5) 160 characters used well — no padding, no setup the punchline doesn't need, every word works.

## 1. Phantom phone vibration — 151 chars — 24/25 ⭐ WINNER

> v2.4.1 — Fixed phantom phone vibration: thigh no longer reports incoming calls from an empty pocket. Patch live; ignore future buzzes at your own risk.

| Criterion | Score | Note |
|---|---|---|
| (1) One-line real-life bug, comic | 5 | Phantom vibration is a real, named body/tech misfire; one line, comic throughout. |
| (2) Funny on first read | 5 | The joke has a mechanism: the thigh as a faulty sensor filing false call reports. |
| (3) Real release-note register | 5 | Version number, "Fixed …", "Patch live" — dry, shipped, no setup. |
| (4) Specific, recognisable bug | 5 | Almost everyone has felt the buzz from an empty pocket; instant wince-laugh. |
| (5) 160 chars used well | 4 | 151/160, dense; the closing "at your own risk" is one small extra beat past the fix. |

Why it wins: the funniest mechanism of the set — a body part misreporting
hardware state — stated in deadpan engineering language, with a support-desk
shrug as the closer. No banned topic, no borrowed phrasing.
